# Pixelhav — независимый проект на Nuxt

Сайт о шрифтах и типографике. Nuxt 4.5.2, Vue 3, TypeScript и обычный CSS.
Самостоятельный проект: не требует Sites, аккаунта OpenAI, сторонних ключей или облачной базы.

## Быстрый запуск

Установите Node.js 22.12+ (подойдёт актуальная LTS). Распакуйте архив и откройте папку `pixelhav-nuxt` в VS Code или WebStorm.

```bash
npm ci
npm run dev
```

Откройте адрес, показанный в терминале — по умолчанию http://localhost:3000.
Не открывайте Vue-файлы двойным щелчком: сайту нужен сервер Nuxt.

## Что реализовано

- Главная с собственным изображением и оформлением по референсу: голубое небо, розовая буква, округлые формы и крупная типографика.
- Каталог из 12 реальных гарнитур с кириллицей: поиск по названию, автору и применению, категории, сортировка, свой текст и размер.
- Отдельные страницы шрифтов: предпросмотр, насыщенность, трекинг, курсив при наличии, символы, авторы и источник.
- Скачивание ZIP с настоящими TTF-файлами, лицензией OFL и ссылкой на источник; отдельное скачивание WOFF2 и пример CSS.
- Избранное, сохраняющееся в браузере, три подборки и инструмент сочетания двух шрифтов.
- Четыре готовых оригинальных материала о типографике с отдельными страницами.
- Адаптивная вёрстка, мобильное меню, управление с клавиатуры, русские метаданные, canonical, sitemap.xml, robots.txt, 404.
- Подготовленные адаптивные места под Яндекс РСЯ: в каталоге, под контентом главной и внутри статей.

Шрифты и главное изображение находятся в `public`. Превью не зависят от запросов к Google Fonts.
Избранное локальное: синхронизации между устройствами, аккаунтов и панели управления нет.
Контент редактируется в TypeScript-файлах, затем сайт пересобирается.

## Настройка домена и рекламы

Скопируйте `.env.example` в `.env`. Например, в PowerShell:

```powershell
Copy-Item .env.example .env
```

Либо создайте копию через редактор. Заполните:

```dotenv
NUXT_PUBLIC_SITE_URL=https://pixelhav.ru
NUXT_PUBLIC_YANDEX_RTB_BANNER_ID=R-A-20107695-1
NUXT_PUBLIC_YANDEX_RTB_ARTICLE_ID=
NUXT_PUBLIC_ADS_PREVIEW=false
```

`your-domain.ru` — пример: замените вашим доменом. Поля РСЯ оставлены пустыми намеренно.
Нужны **реальные ID блоков вашего кабинета** Рекламной сети Яндекса; проект не использует чужие ID.
Подробности подключения и расположение мест — в [docs/RSYA.md](docs/RSYA.md).

Если хотите увидеть пустые размеченные рекламные места до получения ID, задайте
`NUXT_PUBLIC_ADS_PREVIEW=true`. Без ID и с `false` пустые места скрыты, скрипт Яндекса не загружается.

После изменения `.env` перезапустите режим разработки. Для статического размещения обязательно пересоберите сайт.
В продакшене SSR задавайте переменные средствами хостинга: `node .output/server/index.mjs` не читает `.env` автоматически.

## Размещение на обычном сервере с Node.js (SSR)

```bash
npm ci
npm run build
npm start
```

Сайт работает на порту 3000, по умолчанию на интерфейсе `0.0.0.0`.
Запускающий скрипт устанавливает `NODE_ENV=production`. Для постоянной работы используйте процесс-менеджер вашего сервера.
HTTPS и собственный домен настраиваются у хостинга или через reverse proxy.
Копируйте на сервер всю `.output` и `scripts/start.mjs`, сохраняя относительные пути.

Порт можно задать переменной `PORT`.
В PowerShell: `$env:PORT=3000`; в bash: `PORT=3000 npm start`.

## Статический хостинг (SSG)

Для каталога и журнала подходит и статическая генерация. Nuxt заранее создаёт HTML страниц, сохраняя интерактивность Vue.

```bash
npm ci
npm run generate
```

Загрузите **содержимое `.output/public`** в корень сайта. Результат генерации не требует Node.js.
Доменные и рекламные переменные должны быть заполнены перед этой командой — они попадут в статические файлы.
Сервер должен поддерживать директории с `index.html`. Готовая конфигурация nginx — [docs/nginx-static.conf](docs/nginx-static.conf).
После `generate` для SSR снова выполните `npm run build`.

`npm run generate` создаёт sitemap.xml из списка шрифтов, подборок и статей.
Если домен не задан, sitemap пуст, canonical не выводится: вымышленные адреса не используются.
Укажите ваш домен перед публикацией.

## Где менять содержимое

| Что | Файл |
| --- | --- |
| Карточки и описания шрифтов | `app/data/fonts.ts` |
| Авторы, файлы, веса, источники | `app/data/font-assets.json` |
| Подборки | `app/data/collections.ts` |
| Статьи журнала | `app/data/articles.ts` |
| Главная | `app/pages/index.vue` |
| Цвета, отступы, адаптивность | `app/assets/css/main.css` |
| Объявления font-face | `app/assets/css/fonts.css` |
| Компонент РСЯ | `app/components/AdSlot.vue` |
| Настройки проекта | `nuxt.config.ts` |

Для нового шрифта добавьте лицензированные файлы, метаданные, редакционную карточку и правило `@font-face`.
В наборе символов указывайте только знаки, которые реально есть в файле.
Поддерживайте количество гарнитур в текстах главной и каталога при расширении базы.

## GitHub

Проект готов для отдельного репозитория. На вашем компьютере, если установлен GitHub CLI:

```bash
git init
git add .
git commit -m "Rebrand site as Pixelhav"
gh repo create pixelhav-nuxt --private --source=. --remote=origin --push
```

Для публичного репозитория осознанно замените `--private` на `--public`.
`.env`, зависимости и сгенерированные файлы исключены из Git. GitHub Pages подходит только для статической версии.
Для Pages в подпапке `/repository/` потребуется настроить baseURL и пути к публичным файлам; обычный собственный домен в корне работает без этой настройки.

## Авторы и лицензии

Шрифты распространяются по своим OFL-лицензиям, приложенным к файлам и архивам. Авторские сведения и исходные проекты перечислены в каталоге.
Рисунок для главной создан специально для этого проекта. Приложенный референс и чужие логотипы в поставку не включены.
Исходные проекты шрифтов: ссылки `source` в `app/data/font-assets.json`.

Официальная документация Nuxt: [размещение сайта](https://nuxt.com/docs/4.x/getting-started/deployment).
