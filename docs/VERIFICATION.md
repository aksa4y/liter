# Проверка поставки

Дата: 13 сентября 2026.

- `npm run typecheck` — успешно, TypeScript-ошибок нет.
- `npm run build` — успешно, production-сборка Nitro для Node.js.
- SSR-сборка не предгенерирует HTML: домен и ID РСЯ читаются из окружения запущенного сервера.
- `npm run generate` — успешно: 27 страниц сайта плюс служебные 200/404 и payload-файлы.
- У всех 27 страниц проверены русская локаль, заголовок, description и ровно один H1.
- Все локальные ссылки на страницы, CSS, JS, изображения и скачиваемые файлы в предгенерированном HTML разрешаются в существующие файлы.
- Проверены 12 ZIP-архивов: читаются без ошибок, содержат TTF и OFL. Размеры в карточках совпадают с архивами.
- Проверено наличие заявленных символов в исходных TTF-файлах и сигнатуры 18 файлов WOFF2.
- Без ID рекламный скрипт не включается в HTML. Реальный показ рекламы не проверялся: для него нужны ID владельца и домен с подключённой площадкой.

Визуальная и интерактивная проверка в браузере не завершена: браузер среды не получил доступ к локальному серверу (`ERR_CONNECTION_REFUSED`).
Проект не публиковался на внешний хостинг и не отправлялся в GitHub. Поставка — самостоятельные исходники с воспроизводимой установкой по `package-lock.json`.
